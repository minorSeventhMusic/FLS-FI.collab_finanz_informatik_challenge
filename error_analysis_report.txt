From: Testing Team
To: Development Team

Subject: Issues found with the loan calculator - 3 problems discovered

Date: April 9, 2026

We tested the loan calculator and found 3 problems that need fixing.

ISSUE #1: The calculator rejects negative loan amounts
We tried to calculate a loan for -$1000. The calculator said "No" and rejected it.
This shouldn't happen in normal use, but we need to block it properly so people don't try this.

ISSUE #2: The calculator rejects zero-month loans
We tried to calculate a loan for 0 months. The calculator said "No" and rejected it.
People shouldn't be able to set the loan length to zero.

ISSUE #3: The calculator rejects interest rates above 15%
We tried to use a 20% interest rate. The calculator said "No" and rejected it.
The system only allows rates up to 15%.

WHAT NEEDS TO WORK:
- Loan amount must be positive (greater than $0)
- Loan duration must be at least 1 month
- Interest rate must be between 0% and 15%

The calculator is currently blocking these invalid inputs, which is good. But we wanted to report what we found.

Can you review this?

[Testing Team]
